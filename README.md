# نظام إدارة وتأجير المعدات والتقارير المالية

نظام صمم من قبلي في تجربة تعليمية وهو يحاكي نظام إدارة وتأجير المعدات والتقارير المالية وتتبع العملبات واصدار التقارير والاحصائيات والمشروع مكتوب بي لغة **go**

## 📋 المتطلبات الأساسية (Prerequisites)
قبل البدء، تأكد من تثبيت الأدوات التالية على جهازك:
* **Go:** إصدار حديث (Go 1.20 أو أحدث). للتحقق: `go version`
* **Git:** للتحكم بالإصدارات وإدارة المستودع. للتحقق: `git version`
---
## 🚀 التثبيت والتشغيل (Getting Started)
### 1. استنساخ المستودع (Clone) والدخول إليه:

```bash
git clone https://github.com/AbdAlmuhimn-Ai/GO-leraning.git
cd GO-leraning
```

# لي تشغيل البرنامج من الجدر

```bash
go run ./exam04
```


# لي تشغيل الاختبارات

```bash
go test ./exam04
```

يوفر مشروع Go مجموعة من الأدوات القياسية لإدارة الكود وجودته:

go mod tidy
يقوم بمزامنة وترتيب حزم التبعيات (Dependencies) في ملف go.mod؛ يحمّل المكتبات الناقصة ويزيل غير المستخدمة.
go fmt ./...
يقوم بتنسيق وترتيب الكود تلقائياً وفق المعايير القياسية الرسمية للغة Go في جميع المجلدات.
go vet ./...
يقوم بفحص الكود وتحليله لاكتشاف الأخطاء المنطقية أو التركيبات المشبوهة (Static Analysis) قبل التشغيل.
go test ./...
يقوم بتشغيل جميع الاختبارات الآلية (Unit Tests) في جميع حزم ومجلدات المشروع للتأكد من سلامة الكود.
